Pixel 8 Ball 🎱

A little pixel art Magic 8 Ball. Type a question, click the orb, and watch the triangle spin to reveal a random answer.

## Play

Open [the live site](https://eantan2.github.io/pixel-8-ball/) once GitHub Pages is enabled, or open `index.html` in a web browser.

## Features

- Pixel inspired design and animated 8 ball
- Nine classic Magic 8 Ball answers
- Type a question and press Enter, or click the ball
